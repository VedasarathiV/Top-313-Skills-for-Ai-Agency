Clone this repo and install all 313 skills into your local Antigravity environment with one command:

## 🛠️ Installation Options

### Option 1: macOS & Linux (Bash)
```bash
chmod +x install.sh
./install.sh
```
To install to a custom path:
```bash
./install.sh /path/to/custom/skills
```

### Option 2: Cross-Platform (Python)
Works natively on macOS, Linux, and Windows:
```bash
python3 install.py
```
Or with custom target directory:
```bash
python3 install.py --target /path/to/custom/skills
```

### Option 3: Manual Drag & Drop
Copy the contents of `skills/` directly to:
* **macOS / Linux**: `~/.gemini/config/skills/`
* **Windows**: `%USERPROFILE%\.gemini\config\skills\`
